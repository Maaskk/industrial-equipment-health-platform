# Hajar - API Contract and Demo Experience

GitHub: `HajarEnnajdy`

Branch: `feature/HajarEnnajdy-api-demo`

## Why this role fits

Public GitHub history shows JavaScript/backend and web project practice. This role focuses on clean API contracts, request/response examples, and demo usability.

## Mission

Make the model understandable and easy to demo through a clean API and simple user flow.

## Main Deliverables

- API request and response schemas with Ossama.
- Sample prediction payloads.
- API documentation examples.
- Optional lightweight demo client or Postman/HTTP collection.
- Demo script for the final presentation.
- Error-response examples for invalid input.

## Acceptance Criteria

- `POST /predict` has a clear input contract.
- `GET /health` communicates useful service and model status.
- Demo payloads work with the final model.
- Invalid input returns understandable errors.
- The final demo can be rehearsed in under 10 minutes.

## First Tasks
