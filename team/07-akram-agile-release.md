# Akram - Agile, Release, and Final Presentation

GitHub: `Adonis-I`

Branch: `feature/Adonis-I-agile-release`

## Mission

Keep the project organized and make the final delivery look professional.

## Main Deliverables

- Product backlog.
- User stories.
- Sprint planning for at least 3 sprints.
- Sprint review notes.
- Sprint retrospective notes.
- Release checklist.
- Final presentation structure.
- Final report coordination.

## Acceptance Criteria

- Agile artifacts satisfy the course requirements.
- Every task has an owner and sprint.
- Sprint notes are specific, not generic.
- Final presentation fits:
  - 15 minutes presentation
  - 10 minutes demo
  - 5 minutes questions
- The release checklist confirms all mandatory deliverables.

## First Tasks

1. Create the initial product backlog.
2. Convert each team file into user stories.
3. Plan the 3 sprint timeline.
4. Track progress and blockers.
5. Coordinate final report sections.
