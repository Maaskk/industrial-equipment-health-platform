# Agile Plan

## Sprint 1 - Foundation

- Confirm dataset and project vision.
- Create repository, branches, and task ownership.
- Implement raw data ingestion skeleton.
- Define initial DuckDB schema and data contract.
- Build baseline EDA and first feature definitions.

## Sprint 2 - MLOps Core

- Complete dbt transformations and tests.
- Train baseline and improved ML models.
- Track experiments with MLflow.
- Build FastAPI `GET /health` and `POST /predict`.
- Add Docker and first GitHub Actions workflow.

## Sprint 3 - Industrialization and Demo

- Add Dagster orchestration.
- Add model registry and loading strategy.
- Add monitoring for latency, health, drift, and prediction logs.
- Finalize documentation and demo script.
- Prepare final report and presentation.

## Definition of Done

- Code is merged through pull request.
- Tests or validation evidence is included.
- Documentation is updated.
- The feature can run locally or has a clear mock/demo path.
