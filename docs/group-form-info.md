## Username Rules

The form requires usernames with:

- lowercase letters only
- no spaces
- no accents
- `.` or `_` allowed as separators

Recommended pattern:

```text
firstname.lastname
```

## Password Guidance

Each student creates their own password following the form rules:

- at least 8 characters
- at least 1 lowercase letter
- at least 1 uppercase letter
- at least 1 digit
- at least 1 special character

Never submit a shared group password. Never commit passwords to git.

## Name Fields

- First Name: official first name, first letter uppercase.
- Last Name: official family name in uppercase.
- Email: each student's own valid email, checked carefully before submission.

All members must use exactly the same group name: `AeroReliability Lab`.
