# Data Sources and Licenses

## Primary Dataset

**NASA Turbofan Engine Degradation Simulation Data Set**

- Official repository page: https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/
- NASA Open Data metadata page: https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data
- Direct download listed by NASA PCoE: https://phm-datasets.s3.amazonaws.com/NASA/6.+Turbofan+Engine+Degradation+Simulation+Data+Set.zip
- Domain: predictive maintenance, prognostics, remaining useful life.
- Data type: multivariate time series sensor readings from simulated turbofan engines.
- Target: Remaining Useful Life (RUL) regression, with optional failure-risk classification.

NASA describes the dataset as four simulated run-to-failure sets generated with C-MAPSS under different operating conditions and fault modes. Each engine has cycle-level operational settings and sensor channels.

## Required Citation

Use this citation in the report, README, slides, and notebooks:

```text
A. Saxena and K. Goebel (2008). "Turbofan Engine Degradation Simulation Data Set",

```

## Dataset Usage Notes

- Do not commit raw NASA data files into this repository.
- Keep raw files under `data/raw/`, which is ignored by git.
- Provide download instructions or a downloader script instead of redistributing the dataset.
- Always acknowledge NASA Ames Prognostics Center of Excellence as the source.
- Do not imply NASA endorsement of the project.

## Recommended First Scope

Start with `FD001` for Sprint 1 and Sprint 2 because it has one operating condition and one fault mode. Add `FD002` to `FD004` only after the end-to-end pipeline works.
