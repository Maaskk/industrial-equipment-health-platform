Project guide

Documentation

Project scope

NASA C-MAPSS is a simulated turbofan degradation dataset. This application replays historical simulation cycles; it does not receive a live NASA stream.

Evaluation policy

Operations mode uses only past and current observations. Evaluation mode reveals test labels solely for offline comparison and is never presented as deployable truth.

CI experiment scope

CI exercises the complete pipeline with FD001 for practical runtime. The saved final evaluation uses FD001-FD004.

Monitoring limitation

Monitoring is a course-level predicted-RUL mean-shift indicator. It is not full feature or concept-drift detection.
